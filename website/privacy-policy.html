This draft describes the current local version of Second Brain Graph, a program that reads Markdown files from a directory selected by its operator and creates a graph on that computer. No hosted service or account system is configured in this repository.

Information processed on your computer

The program reads Markdown note contents to find explicit wikilinks and, when semantic analysis is enabled, to calculate local text embeddings. The embedding cache stores vectors and file fingerprints, including a content digest, file size, modification time, and model identifier. The cache does not store the original note text.

Generated HTML and optional JSON can include note titles, vault-relative paths, links, similarity scores, and graph statistics. Review those files before sharing them. The generated graph does not include the full note bodies.

Network requests

Semantic analysis uses a Sentence Transformers model. If the model is not already available locally, the software downloads model files from the configured model provider. The note text is processed on the operator's computer and is not sent to an embedding API by this application. Installing dependencies also contacts the package indexes configured for Python.

Retention and deletion

Notes, cache files, and generated exports remain under the locations chosen by the operator. The operator can remove the generated HTML, JSON, and .second_brain cache directory using the file manager or command line.
